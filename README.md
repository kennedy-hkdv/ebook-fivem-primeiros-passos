## 🎯 Para quem é

Para quem quer criar scripts e sistemas para servidores FiveM e não sabe por onde começar. Você sai daqui sabendo montar um servidor de testes, criar um *resource*, usar eventos e comandos, e organizar seu código.

> **Pré-requisito:** noções básicas de Lua. Se precisar, comece pelo ebook [**Lua do Zero**](https://github.com/kennedy-hkdv/ebook-lua-do-zero).
